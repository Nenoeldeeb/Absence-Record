## Conventions Used In This Plan

- **Time model**: Times are **minutes-of-day `Int`** snapped to `:00`/`:30`. Lesson duration is the constant `60` — never stored. Use `ScheduleRules` constants (`LESSON_DURATION_MINUTES`, `SNAP_MINUTES`, `DAY_MINUTES`, `MIN_BUSY_DURATION_MINUTES`) and `ScheduleRules.overlaps(aStart, aEnd, bStart, bEnd) = aStart < bEnd && aEnd > bStart` as the single source of truth for all conflict checks.
- **Weekday**: `kotlinx.datetime.DayOfWeek` in the domain/UI; Room stores `isoDayNumber` (`1..7`). NO `java.time` anywhere. Time *display* via `TimeFormatter` (`java.util.Calendar` + `android.text.format.DateFormat` — permitted; NOT `java.time`).
- **Time entry UX**: `ExposedDropdownMenuBox` slot lists (**47** × `:00`/`:30` slots for lesson-hour starts, `0..1380`; **48** × `:00`/`:30` slots for busy starts, `0..1410`; fixed duration list 15/30/45/60/90/120/150/180/240 for busy) — NEVER Material3 `TimePicker` (no minute-step API; snap must be enforced by construction).
- **Atomic invariants**: All read-check-write flows (`insertHour`, `updateHour`, `assignStudent`, busy insert/update) are `@Transaction` concrete DAO methods. `updateHour`/busy insert/update return removed student ids as `AssignmentRemovalReport` (FR-011/FR-017) → surfaced as a pluralized `UiText` toast in the ViewModel.
- **Eligibility** for the assign dialog is a **pure computation** in the ViewModel/delegate: `allStudents − assignedStudentIds − studentsWithBusyOverlapForThisHour` (no DAO round-trip per row).
- **No class filter** on Schedule: load all students via `getAllStudentsUseCase(SortType.ByName, null)` (spec: class-level filtering out of scope).
- **Pager**: `MainScreen` becomes 3 pages (0 Students, 1 Calendar, 2 Schedule); `AppNavigation` keeps `rememberPagerState(initialPage = 1, pageCount = { 3 })`. No navigation library; `AppDestination` back-stack unchanged.
- **Structure**: Every new file (main + test) MUST stay ≤ 300 lines (constitution V). `ScheduleViewModel` delegates to `HourManagementDelegate` / `AssignmentDelegate` / `BusyManagementDelegate`; UI splits into `components/` + `dialogs/`. Mirrors the `students/` handler/delegate pattern.
- **Strings**: All new copy added to BOTH `app/src/main/res/values/strings.xml` and `app/src/main/res/values-ar/strings.xml` and wrapped in `UiText`. No hardcoded strings.
- **Package root for all main-source paths below**: `app/src/main/java/dev/nenoeldeeb/education/absencerecord/`
- **Unit test root**: `app/src/test/java/dev/nenoeldeeb/education/absencerecord/`
- **Instrumented test root**: `app/src/androidTest/java/dev/nenoeldeeb/education/absencerecord/`
